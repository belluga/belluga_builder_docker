# Registry TEACH v1 conformance

The Registry owner publishes `teach_diagnostic.schema.json` and uses
`TeachDiagnostic` for additive TEACH v1 guidance. Error responses from
`Handler.writeError` cover identity, tenant/project resolution, repository
binding, TODO/planning, Knowledge, Overview, Design System, prototype,
landing, and artifact operations. The session guard and TODO body-size rejection
write through the same bounded error envelope while retaining their legacy
status and fields.

Eligible 2xx state guidance is attached by its owning response constructor:

| Owner response | State or event | Diagnostic source |
| --- | --- | --- |
| Canonical manifest/read | pending knowledge | `canonical_test.go:TestPendingCanonicalHandlerEmitsVersionedDiagnostic`, `canonical_test.go:TestCanonicalTEACHReturnsFieldRecordAcceptedValuesAndNextAction` |
| Overview read/write replay | not_authored, invalid, stale Knowledge origin | `overview_test.go:TestMongoOverviewFreshTenantHTTPPublicationAndReadback`, `overview_test.go:TestMongoOverviewIdenticalReplayPrecedesCurrentManifestValidation` |
| Project portfolio item | not_authored, invalid, unavailable | `portfolio_git_test.go:TestMongoPortfolioCatalogEmitsTEACHForNotAuthoredInvalidAndUnavailable` exercises `ReadPortfolioCatalog` through the real Handler |
| Design System state/mutation/recovery | pending operation, confirmed or uncertain operation outcome | `http_test.go:TestDesignSystemMutationRoutesAreScopedBoundedAndProofFree`, `design_system_http_test.go:TestDesignSystemMutationHTTPRoutesPersistVerifyAndFinalizeDisposableGit` |
| Roadmap TODO view | unverified delivery stage | `todo_test.go` migrated Roadmap assertions |
| TODO image upload | already attached or confirmed attachment | `todo_images_integration_test.go:TestMongoTODOImageUploadLinksOnlyVerifiedGitBytes` asserts the store owner output; `todo_images_test.go:TestTODOImageHTTPRequiresBoundSessionAndExactPath` covers serialization |
| Registry mutation error context | unknown result + known operation ID, preserving typed cause | `http_test.go:TestLocalProofTransitionReturnsFieldSpecificTEACHOverHTTP`, `session_test.go` session bind/read continuity, canonical mutation handlers |
| TODO size rejection | pre-service rejection with `effects=none` | `http_test.go:TestTODOBodyLimitReturnsActionable413OnBothDecoderReads` |

Effects and retry values are included only where the owner has evidence. Read
states use `not_applicable`; a pending or uncertain Design System operation uses
`unknown` and its exact operation ID; a confirmed write uses `committed`.
Errors without stage evidence do not claim a write effect. No `category` field
is part of v1. Error JSON is bounded as a complete encoded envelope, including
the final newline, to 64 KiB. Ordinary successful payloads retain their route
limits. JSON Schema `maxLength` is a character limit; runtime bounds diagnostic
strings by UTF-8 bytes, arrays by item count, and the complete error envelope
by encoded bytes. Consumer proxies/clients are handled in checkpoint 3; this
Registry matrix records server emission only. Binary media, HEAD/304, internal
Reader formats, and framework-generated unknown-route/method responses do not
use this JSON diagnostic contract.
